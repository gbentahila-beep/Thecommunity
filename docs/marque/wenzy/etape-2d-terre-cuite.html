Terre cuite, atlantique et un soleil

On repart de votre planche : ses cinq couleurs, le soleil à côté du nom, les arches pour les photos et les pastilles safran pour les univers. Le nom s'écrit en minuscules, pour éviter un grand W. Le symbole est un soleil dans une arche, sans lettre. Il reste à choisir la police du logo parmi les six ci-dessous.

Le symbole

Un soleil dans une arche : la porte d'un riad qui s'ouvre sur une journée ensoleillée. Il remplace le W, sert d'icône d'application, d'avatar Instagram et de favicon, et se décline dans les trois couleurs de fond.

Six polices pour le logo

Même soleil, mêmes couleurs : seule l'écriture change. En haut sur terre cuite (le logo principal), en dessous sur sable.
